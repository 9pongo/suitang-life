# 天下一戶

投胎到隋唐，一代一代活下去：從開皇元年（581）隋代北周，一路到廣德元年（763）安史之亂平定。你是籍帳上的一戶人家：被里正貌閱、填手實、受田、交租庸調、服役；可能被徵去開運河、征遼東，可能在隋末投了義軍，也可能在貞觀、開元的好年頭裡安安穩穩種一輩子地。一個人死了，由子女或弟妹接下這個家；香火斷了，這一家的故事才算完。

故事往前走的時候，頂部有一面「燈影戲的幕」跟著換景：後頭是各地的水墨山水與村落，村子的屋數與景況隨年代盛衰（徭役、兵亂、殘破、富庶），某些年份才有的地標（大興城、東都、慈恩寺塔、明堂、天樞、北大像……）會在那一年出現；幕前是這一家人的皮影，衣著隨時代改變；右邊是這件事的道具。

## 檔案

| 檔案 | 用途 |
|---|---|
| `engine.js` | 遊戲引擎（瀏覽器和 Node 共用），不含任何劇情，也不含任何朝代的字眼 |
| `ui.html` | 介面。打包時把引擎和資料塞進來；介面上跟朝代有關的字都從 `data/strings.json` 讀 |
| `load.js` | 讀取並合併 `data/` 底下的資料 |
| `data/world.json` | 世界設定：章節、年號、各地歸誰管（`powers`、`regionControl`）、地區、家世、天賦、勢力、路線、死亡率、傳承規則、後記 |
| `data/strings.json` | 文字：干支與數字（`calendar`）、引擎產生的句子（`engine`）、介面上的標題與說明（`ui`） |
| `data/scenes.json` | 插圖：各地山水、村落盛衰、地標、各時期衣著、每種情節的道具 |
| `data/events_*.json` | 事件卡：人生（`life`）、隨機小事（`flavor`）、隋（`sui`）、唐（`tang1`～`tang3`）、歷史人物（`bonds`）、故事線（`arc_*`：仕途、宮人） |
| `data/endings.json` | 結局（章末與身故），由上往下找第一個符合的 |
| `sim.js` | 稽核與模擬：靜態檢查、執行時一致性檢查、統計報告 |
| `assets/cover.js` | 產生分享用的封面圖 `assets/cover.png`（1200×630，用介面的插圖畫法，需要本機有 Chrome）；事件卡、結局數改變很多時重跑一次 |
| `build.js` | 先跑稽核，再打包成 `dist/index.html`（發佈用）與 `dist/dev.html`（本機預覽用） |

## 工作流程

```bash
node sim.js 10000     # 稽核＋模擬一萬條人生，報告寫到 reports/sim_report.md
node build.js         # 打包；稽核有錯誤或頁面腳本有語法錯誤時不會產生檔案
```

本機預覽請開 `dist/dev.html`。目標是每次修改後 **錯誤 0、提醒 0**：跑兩千條以上時，從沒觸發的事件、從沒被選到的選項也算提醒。

## 換一個朝代

引擎與介面不寫死任何朝代：換一份 `data/` 就是另一個時代。要準備的是：

- `world.json`：章節、年號（`eras`，可依政權分開寫在 `powers[].eras`）、地區與各地的統治者時間表（`regionControl`）、家世（`classes`，可用 `regions` 限定出生地、用 `surnames` 指定姓氏）、勢力與路線（`factions`、`routes`）、傳承與遷居的規則、稽核用的字詞（`audit`）。
- `strings.json`：標題、開場、分享圖上的字、引擎產生的句子。
- `scenes.json`：各地的山水與地標、衣著、道具的擺法。
- 事件卡與結局。

## 事件卡

```json
{
  "id": "h721_kuohu", "kind": "stage", "year": [721, 724], "order": 20,
  "req": { "anyFlag": ["taohu"], "noflag": ["kuohu_done"], "age": [16, 80] },
  "tag": "括戶", "title": "括戶", "scene": "registry", "text": "……",
  "note": "史料出處（介面上的小字「史」）",
  "choices": [ { "t": "選項", "req": {}, "show": {}, "lock": "條件不足時的說明", "eff": {}, "out": "結果", "deathOut": "這一下沒活過去時的結果" } ]
}
```

- `kind`：`anchor`（史實大事）、`stage`（人生階段與劇情）、`bond`（歷史人物羈絆）、`flavor`（隨機小事）。
- `scene`：插圖要換成哪一幕（`data/scenes.json` 的 `scenes`）。
- `req` 除了年齡、地區、家世、旗標之外，`power`／`nopower` 看的是住處這一年歸哪個政權管。
- 標 `campaign` 的卡是上陣打仗：那一年家鄉的小事輪不到這個人。

## 史料

大事依《隋書》《舊唐書》《新唐書》《資治通鑑》《唐六典》《通典》，日常依敦煌、吐魯番出土的戶籍、手實、差科簿、便麥契、社條。每張大事卡都附出處。
